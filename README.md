Ringrunner Archipelago: a chase-view flight game over an island archipelago — fly the ring course, manage fuel and damage, then land on the home runway.

## Run it

```sh
node main.ts
```

Serve the game locally with `node serve.ts`, then open http://localhost:8080. Controls: arrows/WASD steer, Shift/Ctrl throttle, P pause, R restart.
